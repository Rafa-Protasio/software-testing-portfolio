# 🧪 Software Testing Portfolio | Rafaela Protasio

Bem-vindo(a) ao meu portfólio de **Quality Assurance (QA)**! Este repositório reúne casos de teste, estratégias, mapeamentos em BDD/Gherkin e suítes de testes automatizados para aplicações web e APIs.

---

## 📌 Estrutura do Portfólio

- **`/casos-de-teste`**: Documentação de cenários de teste funcionais, regras de negócio e especificações em BDD (Gherkin).
- **`/testes-de-api`**: Coleções do Postman/Insomnia e automações para validação de endpoints REST.
- **`/automacao-e2e`**: Projetos de automação de testes end-to-end (E2E) para interface web.

---

## 🛠️ Tecnologias e Ferramentas

- **Planejamento & Estratégia:** BDD, Gherkin, Casos de Teste, Plano de Testes
- **Testes de API:** Postman, REST
- **Automação & Linguagens:** JavaScript, Cypress / Playwright
- **Versionamento & CI/CD:** Git, GitHub, GitHub Actions
